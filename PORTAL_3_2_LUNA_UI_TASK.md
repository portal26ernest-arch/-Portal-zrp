# PORTAL 3.2 — Luna: русские подписи Android

Работай только в `android_src/app/src/main/assets/` и существующих Android/JS тестах, если необходимы осмысленные проверки. Другая сессия редактирует серверные файлы; не меняй, не откатывай, не индексируй и не коммить её изменения. Не меняй зарплату, PostgreSQL, миграции, API, тарифы, версию и номер сборки. Не собирай release APK.

Прочитай раздел о локализации в `PORTAL_3_2_BASELINE_AUDIT.md` и проверь реальные строки в исходниках. Замени только видимые человеку английские статусные подписи, англоязычные слова в русских сообщениях и техническое слово snapshot на понятные русские формулировки. Сохрани машинные значения JSON, API keys, permission codes, CSS classes, имена файлов и форматы XLSX. Особое внимание Online/Offline, состояния документов и тарифов, названия действий. Убедись, что итоговые фразы помещаются в мобильный интерфейс и отражают смысл состояния.

Проверь существующими Android/JS тестами и поиском по видимым строкам. Добавь тест только если он проверяет реальный контракт локализации, а не копирует реализацию. В отчёте перечисли точные изменённые файлы, тесты, оставшиеся английские пользовательские строки и ограничения. Если обнаружишь, что строка приходит с сервера, только зафиксируй её без правки серверного кода. Не трогай устройство, APK и production.
