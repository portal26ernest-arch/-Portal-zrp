PORTAL Android 2026.09.24-b002 — сервер 2026.09.24-a002

1. Обновите portal_app_server.py и start_portal_app.sh в папке server
   репозитория PORTAL-Android. Файлы должны находиться рядом.
   База остаётся по прежнему пути: /storage/emulated/0/PORTAL-BOT/portal.db.

2. Остановите Telegram-бот, если он сейчас занимает терминал (Ctrl+C).
   Сам Telegram-бот для работы APK не нужен.

3. Запустите сервер PORTAL:
   bash /путь/к/PORTAL-Android/server/start_portal_app.sh
   Скрипт можно вызвать из любой текущей папки.

4. Должно появиться:
   PORTAL Android Server · 2026.09.24-a002
   Сервер: http://0.0.0.0:8765

5. Установите PORTAL_Android_2026.09.24-b002.apk после успешной сборки.
   При самом первом запуске создайте администратора на телефоне сервера
   через адрес http://127.0.0.1:8765. Существующие доступы сохраняются.

На телефоне сервера адрес APK остаётся http://127.0.0.1:8765.
На других телефонах в той же сети укажите в настройках APK:
http://<IP-телефона-сервера>:8765 (0.0.0.0 не является адресом для входа).
Для чтения данных нужен вход, для управления доступами и справочниками — admin.

Администратор: «Доступ» → создать или изменить сотрудника, роль, PIN,
привязку к сотруднику PORTAL и активность доступа. Для упаковщика привязка
обязательна. После изменения доступа старые сессии отзываются.
Последнего активного администратора отключить или понизить нельзя.

«Клиенты» → добавить, переименовать, архивировать или восстановить.
«Работы» у клиента → добавить, переименовать, включить/отключить,
изменить ставку сотруднику и цену услуги клиенту.
Архивные клиенты и отключённые работы недоступны для новой выработки.
Переименования обновляют текстовые связи в базе; ID, количества и уже
начисленные суммы сохраняются. Новые ставки действуют на новые записи.

ВАЖНО: portal.db остаётся прежней. APK использует существующие данные PORTAL.
При отсутствии базы сервер завершается с ошибкой и не создаёт пустую базу.

Проверки в репозитории:
  python -m py_compile server/portal_app_server.py
  python -m unittest discover -s server -p 'test_*.py' -v
Тесты используют временную базу с тестовой схемой, а не базу телефона.
Для дополнительной проверки через локальные TCP-соединения установите
PORTAL_TEST_HTTP=1 перед запуском тестов.
