# PORTAL Android installation

Рабочая production-архитектура: приложение подключается к HTTPS API PORTAL на VPS.
Не запускайте сервер приложения на Android/Termux как штатный production-контур.
До завершения cutover текущий телефон хранит исходную SQLite-базу только как действующий legacy-контур и источник финального снимка.

Staging-пакет ru.portal.app.staging устанавливается отдельно от рабочего ru.portal.app.
После production cutover рабочее приложение получает HTTPS URL VPS; исходная SQLite сохраняется как rollback-копия и не принимает параллельные записи.
