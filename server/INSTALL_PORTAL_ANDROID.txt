PORTAL Android b001 — установка серверной части на телефон

1. Скопируйте portal_app_server.py и start_portal_app.sh в:
   /storage/emulated/0/PORTAL-BOT/

2. Остановите Telegram-бот, если он сейчас занимает терминал (Ctrl+C).
   Сам Telegram-бот для работы APK не нужен.

3. Запустите сервер PORTAL:
   cd ~/storage/shared/PORTAL-BOT
   python portal_app_server.py

4. Должно появиться:
   PORTAL Android Server · 2026.09.23-a001
   Сервер: http://127.0.0.1:8765

5. Установите PORTAL_Android_2026.09.23-b001.apk и откройте приложение.
   При первом запуске приложение предложит создать администратора и PIN.

По умолчанию APK и сервер работают на одном Android-телефоне через 127.0.0.1:8765.
В настройках приложения можно указать другой адрес сервера, если позже сервер будет перенесён на другой телефон/VPS.

ВАЖНО: portal.db остаётся прежней. APK использует существующие данные PORTAL.
