# PORTAL — отчёт Этапа 4A

Дата: 25.09.2026. Ветка `portal-next-b003`, база работы — контрольная точка Этапа 3 `962b1cb700d1e73752082a18788e99c15264b30d`. В 4A менялись только Android UI, браузерные тесты и этот отчёт. Серверная архитектура, финансовая логика и база данных не менялись. Commit, push, merge и миграция PostgreSQL не выполнялись.

## Экраны и сценарии

- **PORTAL Сегодня.** Руководитель видит только те показатели, которые присутствуют в ответе API и доступны по правам: работу за день, задания в работе, готовые и активные партии, начисления, выручку, ожидаемую прибыль и задолженность. Счётчик заданий выводится из доступных заданий и активных таймеров. При отсутствии финансовых данных финансовые карточки скрыты. «Требует внимания» появляется только при наличии серверных предупреждений. Для сотрудника показаны личная выработка и заработок, его задания и быстрые действия начала работы.
- **Партии и задания.** Карточка показывает номер PORTAL, клиента, товар, дату поступления, принятое, сделанное, остаток, статус и связанные операции/задания. Для приёмки используется существующая форма; внутренний номер не вводится пользователем.
- **Рабочий экран.** Карточки показывают клиента, товар, партию, операцию, нужно/сделано/осталось. Действия начала, паузы, продолжения и завершения используют существующий таймер. В активной сессии отображаются время начала и накопленное чистое время с обновлением на экране.
- **Другая работа.** Кнопка открывает выбор клиента, необязательной партии, разрешённой операции и количества. Запись без задания помечается «Без задания». Экран не даёт создавать операции или менять тарифы.
- **Сотрудники и активность.** В карточках используются компактные зелёный/красный индикаторы Online/Offline, последняя активность в формате «Был в PORTAL сегодня в 08:42» и действие «Активность в системе». История входов показывается только с соответствующим разрешением.
- **Права доступа.** Экран сгруппирован по русским названиям прав; технические коды не выводятся пользователю. Сохранены рекомендации ролей, быстрые действия применить рекомендуемые/скопировать/сбросить. В каталоге прав нет Platform Owner.
- **Навигация и информация о системе.** Нижняя панель остаётся компактной: Главная, Работа, Ещё, Настройки. Полное меню показывает реализованные доступные пользователю разделы; документы и отчёты обозначены как будущие модули. Удалён текст о создании администратора на телефоне сервера. Подпись разработчика одинакова на входе и в информации о PORTAL.

## Ограничения и рекомендации для 4B

- История входов использует существующий API последней страницы событий (до 200 записей); карточка сотрудника фильтрует эту страницу в UI. Для полноценной длинной истории рекомендуется добавить серверную фильтрацию по сотруднику и курсорную пагинацию, сохраняя permission и company_id проверки.
- Серверное поле `in_progress` относится к партиям. UI отдельно вычисляет задания в работе по видимым статусам заданий и активным таймерам. Для упрощения и точной семантики можно добавить отдельные счётчики заданий и работающих таймеров в `/api/v3/today`, защищённые теми же правами.
- В 4A не менялись сервер, API, тайминг, права и финансовые расчёты. Рекомендуемая серверная работа для 4B ограничивается пагинацией активности и явными сводными полями, если потребуется отчётность поверх нескольких устройств.
- После устройства проверить локальное форматирование времени таймера, Android back/закрытие формы в активной сессии, мелкие экраны и длинные списки сотрудников/заданий. APK в рамках 4A не собирался.
