КАК СОБРАТЬ В ANDROID STUDIO
1. Откройте папку android_src как проект Android Studio.
2. Дождитесь Gradle Sync.
3. Build > Build APK(s).
4. APK появится в app/build/outputs/apk/debug/app-debug.apk.

СЕРВЕР НА ТЕЛЕФОНЕ
Скопируйте server/portal_app_server.py в /storage/emulated/0/PORTAL-BOT/
Запуск:
  cd ~/storage/shared/PORTAL-BOT
  python portal_app_server.py
По умолчанию сервер слушает 127.0.0.1:8765.
