# PORTAL APK/Desktop build

Актуальная архитектура: Android APK / будущий Desktop-Web клиент -> HTTPS API на VPS -> PostgreSQL.
Телефон не является целевым сервером и не должен использоваться как production-хост после cutover.
Локальный SQLite допускается только для миграции, тестов и rollback-копии.

Сборка Android выполняется GitHub Actions из android_src.
Единый номер сборки хранится в android_src/release.properties.
Production release должен использовать HTTPS и постоянный Android signing key.
